# COHORT 3.0 — Assignment 4 🏋️‍♀️

## FlexFit — Fitness Landing Page

This is my **4th assignment from Sheryians Coding School's Cohort 3.0**.

I created this fitness-themed landing page using **HTML and CSS**, focusing mainly on layout, positioning, typography, images, and responsive design concepts.

## ✨ About the Project

**FlexFit** is a modern fitness-themed webpage designed to promote:

- 💪 Fitness & workout goals
- 🏋️ Personal trainers
- 🔥 Fitness motivation
- 📱 Fitness mobile app
- 📍 Fitness center information

The design uses a **bento-style layout** with multiple cards, images, text sections, and interactive-looking UI elements.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Positioning
- Images
- Remix Icons

## 🎯 What I Learned

While creating this assignment, I practiced:

- Creating layouts using CSS
- Working with **Flexbox and Grid**
- Using `position: relative` and `position: absolute`
- Placing images inside different sections
- Styling cards and containers
- Working with typography and spacing
- Building a visually appealing webpage from a reference design
